# The Midterm Desk

[View the dashboard](https://tobymanders.github.io/midterm-desk/)

Interactive 2026 polling, market odds, and election forecasts. Sources: Silver Bulletin, FiftyPlusOne, DDHQ, Kalshi, and Polymarket. Updates every six hours.

Preview of the v2 page: `/v2/` on the published site (built from `dashboard.v2.template.html`; `python3 server.py` also serves it at `/v2`).
